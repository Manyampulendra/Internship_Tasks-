# Task 3 – Python Coding & Problem-Solving

## Overview
This task focuses on solving Python programming problems using logical thinking, functions, and built-in data structures.

## Files Included
- **`solutions.py`** – Contains solutions for 15 Python coding problems.
- **`main.py`** – Imports and executes the functions to display their results.
- **`problem_solving.ipynb`** – Jupyter Notebook containing problem-solving logic, explanations, and test cases.

## Topics Covered
- String manipulation
- Dictionaries and character frequency
- Lists and sets
- Duplicate removal
- Searching and sorting logic
- Missing numbers and pair-sum problems
- List rotation
- Test cases and edge cases

## Technologies Used
- Python 3
- Jupyter Notebook

## How to Run
1. Ensure Python 3 is installed.
2. Keep `solutions.py` and `main.py` in the same directory.
3. Open a terminal in the Task 3 folder.
4. Run:

```bash
python main.py
```

## Learning Outcome
Practiced breaking programming problems into smaller steps, implementing reusable functions, and validating solutions with test cases.
