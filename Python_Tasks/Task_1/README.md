# Task 1 – Python Predict and Execute

## Overview
This task focuses on Python programming practice through 50 questions involving code prediction, execution, and understanding program behavior.

## File Included
- **`Python_Predict_and_Execute_Q1-Q50.ipynb`** – Jupyter Notebook containing the 50 Python questions, predicted outputs, and explanations.

## Topics Covered
- Python fundamentals
- Variables and data types
- Operators and expressions
- Conditional statements
- Loops and iteration
- Strings and lists
- Functions and basic problem-solving
- Code execution and output prediction

## Technologies Used
- Python 3
- Jupyter Notebook

## How to Run
1. Open the notebook in Jupyter Notebook, JupyterLab, or Google Colab.
2. Execute the code cells in order.
3. Compare the actual outputs with the predicted results and explanations.

## Learning Outcome
Improved understanding of Python syntax, program execution, output prediction, and logical reasoning.
